# Robot Arm Sorting — feat/IK_and_deep

카메라로 볼트/너트를 실시간 감지하고 역기구학(IK)으로 로봇 팔 모터 각도를 계산하는 파이프라인입니다.

---

## 파일 구성

```
PROJECT1/
├── Robotarm/
│   ├── detect_and_ik.py       # 메인 실행 파일 (감지 + IK 계산 + 모터 각도 출력)
│   ├── ik.py                  # 역기구학 모듈
│   ├── camera_calib.npz       # 카메라 내부 파라미터 (FX/FY/CX/CY, 왜곡계수)
│   └── homography_64cm.npz    # 픽셀 → 실제 좌표(mm) 변환 행렬 (64cm 높이 기준)
└── runs/
    └── bolt_nut_v1/
        └── weights/
            └── best.pt        # YOLOv8 학습 모델 (bolt / nut 2클래스)
```

---

## 시스템 구조

```
[USB 카메라 (로봇 팔 탑재)]
        ↓
[1단계 - 64cm 높이]
  OpenCV 물체 감지 → Homography → 실제 XY 좌표(mm)
        ↓
  로봇 팔 이동 (카메라 중심 → 물체 위)
        ↓
[2단계 - YOLO 촬영 높이 하강]
  YOLO: bolt / nut 분류
  OpenCV: 볼트 기울기 각도 계산 (0~180°)
        ↓
  오프셋 이동 (카메라 → 그리퍼 중심 정렬, X: 85mm)
        ↓
  IK: 픽셀 → 모터 각도 (M1~M6) 계산
        ↓
[다른 PC / RPi → STM32 → STS3215 모터]
```

---

## 로봇 팔 사양

| 항목 | 값 |
|---|---|
| 모터 | STS3215 × 6 |
| 통신 | CAN bus (RPi → STM32) |
| H (바닥 ~ 어깨) | 117 mm |
| L1 (어깨 ~ 팔꿈치) | 245 mm |
| L2 (팔꿈치 ~ 손목) | 213 mm |
| L3 (손목 ~ 그리퍼) | 231 mm |
| 카메라 오프셋 X | 85 mm (그리퍼 기준) |

### 모터 역할

| 모터 | 역할 |
|---|---|
| M1 | 베이스 회전 (yaw) |
| M2 + M3 | 어깨 pitch (mirror pair) |
| M4 | 팔꿈치 pitch |
| M5 | 손목 pitch |
| M6 | 손목 roll (볼트 각도 맞춤) |

## 실행

```bash
python Robotarm/detect_and_ik.py
```

### 조작 키
| 키 | 동작 |
|---|---|
| `C` | 현재 감지 물체의 모터 각도를 터미널에 출력 |
| `Q` | 종료 |
| 마우스 클릭 | 해당 픽셀 좌표 터미널 출력 |
