# Dataset Capture Guide

데이터셋 수집 스크립트 (`dataset_capture.py`) 사용 가이드입니다.

---

## 개요

로봇팔 분류 시스템을 위한 학습 데이터 수집 스크립트입니다.  
카메라를 로봇의 실제 촬영 위치에 고정한 상태에서, 볼트/너트를 손으로 위치를 바꿔가며 촬영합니다.

## 조작 방법

| 키 | 동작 |
|----|------|
| `Space` | 촬영 시작 / 일시정지 |
| `Q` | 현재 클래스 종료 후 다음 클래스로 이동 |

- 초록 테두리: 일시정지 상태
- 주황 테두리: 촬영 중 상태

## 촬영 주의사항

### 카메라 위치
- **반드시 로봇의 실제 작업 위치에 카메라를 고정**
- 촬영 도중 카메라 위치 변경 금지

### 데이터 다양성 확보 (중요)
- 물체를 화면 내 다양한 위치에 놓기 (왼쪽, 중앙, 오른쪽, 위, 아래)
- 각 구간 내에서도 각도를 조금씩 다르게
- 조명 변화도 일부 포함 권장

### 볼트 각도 측정
- 볼트의 긴 축을 기준으로 수평(0°)부터 측정
- 각도기 또는 촬영 보조 도구 사용 권장

### 저장 간격
- 기본 `interval=1.0` (1초마다 자동 저장)
- 손으로 물체 위치 바꾸기에 충분한 시간

## 재촬영

특정 클래스만 재촬영할 경우, `dataset/raw/{class_name}/` 폴더를 삭제 후 재실행하면 해당 클래스부터 다시 시작합니다.  
기존 이미지가 남아있으면 이어서 수집합니다.
