수명예측 계산 기준 / Servo Life Guide
이 패널은 STS3215 공식 보호 한계값, 우리가 모은 정상 자동운전 데이터, 실시간 온도·전류·부하·위치오차를 함께 보고 모터별 상태를 판단합니다.
공식 cycle1 cyc = 60도 왕복 = 총 120도 이동 입니다. STS3215 수명 테스트 조건에 맞춰 Σ|각도 변화| / 120으로 계산합니다.
잔여량100,000 cyc 기준에서 보정 사용 cycle을 뺀 값입니다. 기본 사용량과 보정 사용량 중 더 보수적인 값을 화면에 표시합니다.
상태 보정전류 I², 부하², 온도 초과량, 위치오차를 보고 같은 움직임이라도 더 힘든 작업이면 보정 cycle을 더 크게 누적합니다.
정상 기준 범위우리가 수집한 정상 자동운전 데이터의 온도·전류·부하 분포 안에 있다는 뜻입니다. 공식 수치가 아니라 이 로봇팔 맞춤 기준입니다.
정상공식 한계보다 충분히 낮고, 우리 정상 기준선 안에 있습니다. 즉시 조치가 필요하지 않습니다.
관찰정상 범위에서 살짝 벗어나기 시작한 상태입니다. 운전은 가능하지만 추세를 봅니다.
주의온도, 전류, 부하, 위치오차 중 하나가 평소보다 높습니다. 순간 신호 하나만으로 수명이 바로 크게 줄지는 않고, 부담이 누적될 때 반영됩니다.
점검 권장STS3215 권장 운용 범위 근처이거나 기준선 초과가 큽니다. 쉬게 하거나 기구 간섭을 확인합니다.
위험공식 보호 한계 근처입니다. 자동운전 중단, 냉각, 전원·기구 상태 확인을 우선합니다.
