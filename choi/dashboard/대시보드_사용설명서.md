# 삼보모터스 로봇팔 대시보드 — 사용 설명서

> 처음 보는 사람도 이 문서만 보고 화면을 읽고 조작할 수 있게 쓴 설명서입니다.
> "이 박스는 무엇을 보여주는가 / 이 버튼을 누르면 무슨 일이 일어나는가"를 위에서부터 차례로 설명합니다.

---

## 0. 이 대시보드로 할 수 있는 것

- 로봇팔이 **볼트·너트를 자동으로 분류**하는 과정을 한 화면에서 실시간으로 지켜봅니다.
- 운전을 **시작 / 즉시 정지 / 종료** 할 수 있습니다.
- 로봇의 **관절 각도, 모터 온도·부하, 통신 상태, 거리 센서, 카메라 영상**을 봅니다.
- **3D 화면**으로 지금 로봇이 어떤 자세인지 입체로 봅니다.
- **수동 시험** 모드에서 관절을 하나씩 직접 움직여 볼 수 있습니다.
- 모르는 게 있으면 **AI 도우미**에게 현재 상태를 쉬운 말로 물어봅니다.

> ⚠️ **두 가지 동작 방식**
>
> - **실연결**: 라즈베리파이(로봇)와 연결되면 화면 조작이 실제 로봇을 움직입니다.
> - **DEMO(데모)**: 로봇과 연결 안 됐을 때 자동으로 들어가는 **연습용 모드**입니다. 화면의 값과 움직임은 모두 시뮬레이션이고 실제 로봇은 안 움직입니다. 진짜 데이터가 들어오면 자동으로 실연결로 바뀝니다. (지난번 지운 "긴급 시연"과는 다른 것 — 그건 발표용 자동재생 기능이었고, DEMO는 서버 미연결 시 화면이 비지 않게 해주는 기본 기능입니다.)

---

## 1. 시작 화면 (들어가기)

처음 열면 삼보모터스 인트로 화면이 뜹니다.

- **"운영 화면 열기" 버튼**을 누르거나 **키보드 ENTER** → 실제 대시보드로 들어갑니다.

---

## 2. 화면 맨 위 — 제어 바 (Header)

왼쪽에 로고, 가운데에 버튼·상태표시, 오른쪽에 시계가 있습니다.

### 운전 버튼 3개 (가장 중요)

| 버튼 | 누르면 일어나는 일 |
|---|---|
| **▶ 시작 (AUTO RUN)** | 자동 분류 운전을 **시작**합니다. 로봇이 스캔 자세로 이동하고, 아래 단계 표시가 01→09로 진행됩니다. |
| **⏸ 중지 (HALT)** | **그 자리에서 즉시 멈춤.** 하던 동작을 끊고 **현재 위치 그대로** 정지(힘은 유지). "잠깐 멈춰!" 용도. |
| **■ 정지 (STOP)** | 운전을 **끝냄.** 스캔 자세를 거쳐 **원점(시작 위치)으로 안전하게 복귀**합니다. |

> **중지 vs 정지 차이**: 중지(HALT)는 _지금 위치에 그대로 선다_, 정지(STOP)는 _마무리하고 원점으로 돌아간다_.

### 상태 표시 (점 + 글자)

| 표시 | 무엇을 나타내나 |
|---|---|
| **서버** | 라즈베리파이(로봇)와 연결됐는지. "연결" = 실제 데이터 수신 중, "대기" = 미연결 |
| **CAN** | 로봇 내부 통신 버스 상태. 정상(OK) / 주의(WARN) / 끊김(STALE). 마우스를 올리면 자세한 내용이 뜸 |
| **카메라 · AI** | 카메라와 AI(YOLO) 인식이 동작 중인지 |
| **DEMO MODE** | (떠 있으면) 지금은 로봇 미연결 상태라 화면이 연습용 시뮬레이션으로 돌고 있다는 표시 (연결되면 사라짐) |
| **시계** | 현재 시각 |

> **점 색깔 읽는 법**: 초록 = 정상 / 노랑 = 대기·주의 / 빨강 = 오류.

## 3. 그 아래 줄 — 모드 탭 + 유틸 버튼

### 왼쪽: 모드 전환 탭

| 탭 | 누르면 |
|---|---|
| **자동 운전** | 자동 분류를 지켜보는 화면으로 전환 (기본) |
| **수동 시험** | 관절을 직접 움직여보는 화면으로 전환 |

### 오른쪽: 유틸 버튼 (누르면 창이 뜨거나 동작)

| 버튼 | 누르면 |
|---|---|
| **카메라 보기 / 설정** | 카메라를 고르고 연결하는 **설정 창**이 뜸 |
| **시스템 연결도** | 로봇 하드웨어가 어떻게 연결됐는지 **구성도 창**이 뜸 |
| **통신 상세** | 서버 주소·통신 상태·오류·기록을 보는 **진단 창**이 뜸 |

> 원점 복귀는 상단 **■ 정지**가 스캔 자세를 거쳐 원점까지 돌려주므로, 별도 "HOME 복귀" 버튼은 두지 않습니다.

(각 창의 내용은 아래 8장에서 자세히 설명)

---

## 4. 단계 표시 줄 (자동 운전 진행 상황)

화면 위쪽 가로로 **01 ~ 09 단계**가 표시됩니다. 자동 운전 중에는 지금 어느 단계인지 색이 켜지고, 오른쪽에 진행률(%)이 나옵니다.

| 단계 | 의미 |
|---|---|
| 01 HOME 복귀 | 시작 위치 정렬 |
| 02 스캔 중 | 작업대를 살피는 자세 |
| 03 물체 감지 | 카메라로 볼트·너트 찾기 |
| 04 집기 전 접근 | 대상 위로 다가가기 |
| 05 집기 | 그리퍼로 잡기 |
| 06 들어 올리기 | 들어올림 |
| 07 운반 | 분류통으로 이동 |
| 08 분류통 배치 | 볼트통/너트통에 넣기 |
| 09 HOME 복귀 | 한 사이클 끝, 원점 복귀 |

## 5. [자동 운전] 화면에서 보이는 것들

가운데가 두 칸(왼쪽 카메라 / 오른쪽 3D), 오른쪽에 상태 패널들, 아래에 센서·로그가 있습니다.

### 5-1. 그리퍼 카메라 (왼쪽 위 박스)

- 로봇 손(그리퍼) 근처 카메라의 **실시간 영상**을 보여줍니다. AI가 인식한 표시도 영상 위에 같이 나옵니다.
- 아직 연결 전이면 "CAM" 안내가 보입니다. **그 자리를 클릭하면** 영상 주소(MJPEG)를 직접 입력할 수 있습니다.

### 5-2. 로봇 3D 분류 셀 (오른쪽 위 박스)

- 지금 로봇의 **실제 자세를 입체(3D)로** 보여줍니다. 바닥·볼트통·너트통·스캔 영역도 같이 그려집니다.
- 박스 오른쪽 위 작은 버튼들로 보는 각도를 바꿀 수 있습니다:

| 버튼 / 조작 | 누르면(하면) |
|---|---|
| **↶ 15° / 15° ↷** | 로봇을 좌/우로 15°씩 돌려서 봅니다 (옆 숫자 = 현재 각도) |
| **− / +** | 화면을 축소/확대 (옆 숫자 = 현재 배율 %) |
| **기본 시점** | 처음 보던 기본 각도·배율로 되돌립니다 |
| **마우스로 드래그** | 좌우로 끌면 돌려보고, 위아래로 끌면 내려다보는 각도를 바꿉니다 |

### 5-3. 로봇 관절 상태 (오른쪽 패널 위)

- 관절마다 **현재 각도 / 목표 각도 / 차이 / 상태**를 표로 보여줍니다.
- 5축이지만 어깨가 모터 2개라, 표에는 **J1, J2, J2, J3, J4, J5 + 그리퍼(GR)** 로 나옵니다. (어깨 J2가 두 줄 = 모터 M2·M3)
- 상태칸: "정상"이면 초록, 문제가 있으면 색으로 알려줍니다.

### 5-4. 모터 상태 (오른쪽 패널 가운데)

- 모터별 **온도 · 부하 · 통신** 상태를 막대로 보여줍니다. 과열·과부하·통신 끊김을 한눈에 봅니다.

### 5-5. 분류 현황 (오른쪽 패널 아래)

- 지금까지 **볼트통 / 너트통에 몇 개**를 넣었는지, 총 개수와 사이클을 보여줍니다.

### 5-6. ToF 거리 (아래 왼쪽 박스)

- 그리퍼 앞 물체까지의 **거리(mm)** 와 집기 판단을 보여줍니다.
- 게이지: **접근 필요(멀다) → 집기 가능(18~35mm) → 너무 가까움**.

### 5-7. 예약 영역 (아래 가운데 박스)

- 지금은 비어 있는, **추후 기능용** 자리입니다.

### 5-8. 이벤트 로그 (아래 오른쪽 박스)

- 무슨 일이 언제 일어났는지 **시간순 기록**이 쌓입니다. (정상=초록, 주의=노랑, 정보=일반)

| 버튼 | 누르면 |
|---|---|
| **로그 CSV** | 지금까지의 기록을 **파일(CSV)로 내려받습니다** (엑셀로 열 수 있음) |
| **지우기** | 화면의 기록을 **모두 비웁니다** |

### 5-9. AI 작업 도우미 (오른쪽 아래 떠 있는 동그란 버튼)

- 누르면 채팅 창이 열립니다. **현재 화면 값을 쉬운 말로 설명**해 줍니다.
- **로봇을 움직이지는 않습니다** (설명 전용, 안전).
- 빠른 질문 버튼: "우선 확인 / J3 상태 / 집기 가능? / CAN 상태 / 발표 요약" — 누르면 그 질문에 바로 답해 줍니다.
- 직접 질문도 입력할 수 있습니다.

## 6. [수동 시험] 화면에서 보이는 것들

위쪽 탭에서 **수동 시험**을 누르면 왼쪽이 조작판으로 바뀝니다. (오른쪽 3D는 그대로)

> ⚠️ 실제 로봇이 연결된 상태라면 이 화면의 조작이 **진짜로 로봇을 움직입니다.** 주변 안전을 먼저 확인하세요.

### 6-1. 관절 조작 줄 (관절마다 한 줄)

각 관절(J1~J5)마다 이런 칸들이 있습니다:

| 요소 | 무엇 / 누르면 |
|---|---|
| **슬라이더** | 끌면 그 각도로 **3D에 미리보기**가 움직입니다 (아직 로봇엔 안 보냄) |
| **숫자 입력칸** | 각도를 직접 숫자로 입력 (마우스 휠·방향키로도 조절) |
| **−1° / +1°** | 1도씩 미세 조정 |
| **적용** | 그제서야 **실제(또는 DEMO) 로봇을 그 각도로 이동**시킵니다 |

> **어깨(J2)는 슬라이더 하나로 모터 두 개(M2·M3)를 같이** 움직입니다. (그래서 어깨는 한 줄만 보입니다)
> 잠깐 만지다 적용 안 하면 잠시 뒤 **현재 실제 각도로 자동 환원**됩니다.

### 6-2. 그리퍼 조작 줄 (GR)

- 슬라이더 / 숫자 입력 / **−5° · +5°** / **적용** — 그리퍼를 원하는 각도로 벌리거나 오므립니다.

### 6-3. 아래 공통 버튼

| 버튼 | 누르면 |
|---|---|
| **HOME 이동** | 로봇을 원점 자세로 보냅니다 |
| **그리퍼 열기 / 닫기** | 그리퍼를 한 번에 열거나 닫습니다(토글) |
| **연결 확인** | 통신이 살아있는지 점검하고 로그에 남깁니다 |
| **서보 Torque ON/OFF** | 서보의 힘을 켜고/끕니다. **끄면** 모터에 힘이 빠져 **손으로 관절을 움직일 수** 있습니다 (정렬·자세 잡기용) |

## 7. 상태·색깔 빨리 읽는 법

| 보이는 것 | 의미 |
|---|---|
| 초록 점 / "정상" | 좋음 |
| 노랑 점 / "대기"·"주의" | 준비 중이거나 확인 필요 |
| 빨강 점 / "오류" | 문제 발생 |
| 화면에 **DEMO MODE** 배너 | 지금은 로봇 미연결 — 연습용 시뮬레이션 중 (실제 로봇 아님) |
| 서버 "연결" | 실제 로봇 데이터가 들어오는 중 |

## 8. 위쪽 유틸 버튼을 누르면 뜨는 창들

### 8-1. 카메라 보기 / 설정

- 그리퍼 근처 **AI 인식 카메라**를 고릅니다. (목록은 이 화면을 띄운 PC에 연결된 USB 카메라들입니다)
- **"카메라 다시 검색"**: 연결 가능한 카메라 찾기 / **"선택 카메라 연결"**: 고른 카메라 켜기 / **"카메라 연결 해제"**: 끄기.

### 8-2. 시스템 연결도

- 로봇이 어떻게 연결돼 있는지 그림으로 보여줍니다:
  **라즈베리파이(카메라·AI) → CAN 통신(125k) → STM32(제어) → STS3215 서보 6개 + 그리퍼**.
- 통신 ID, 서보 전원(7.4~7.5V) 같은 정보도 함께 표시됩니다. (읽기용, 조작 없음)

### 8-3. 통신 상세

- **서버 주소 / 통신 상태 / 최근 수신 / 오류 건수**를 보여줍니다.
- 아래에 **디버그 로그**와 데이터 형식(JSON) 예시가 있어, 연결 문제를 진단할 때 봅니다.

## 9. 자주 하는 작업 (흐름 예시)

**① 자동 분류 시작하기**

1. 상단 **▶ 시작** 누르기 → 단계 01→09 진행 지켜보기
2. 끝내려면 **■ 정지** (원점 복귀) / 급하면 **⏸ 중지** (그 자리 정지)

**② 관절 하나만 움직여 보기 (수동)**

1. 위쪽 탭 **수동 시험** 선택
2. 원하는 관절 **슬라이더**로 미리보기 → **적용** 누르면 실제 이동

**③ 손으로 자세 잡기 (정렬)**

1. **수동 시험** → **서보 Torque OFF** → 힘이 빠지면 손으로 관절 이동 → 끝나면 다시 **Torque ON**

**④ 급하게 멈추기**

- 언제든 상단 **⏸ 중지(HALT)** → 그 자리에서 즉시 정지.
- (진짜 비상시엔 하드웨어 **E-STOP**으로 서보 전원을 차단해야 합니다 — 화면 버튼과 별개)

---

## 10. 안전 요약

- **⏸ 중지**: 그 자리에서 즉시 정지(현재 위치 유지)
- **■ 정지**: 마무리 후 원점으로 안전 복귀
- 3D 화면은 통·프레임 **충돌 위험 영역**을 감시해 위험 자세를 막아 줍니다
- 수동 조작은 관절이 **한계 각도를 넘지 않게** 자동으로 막습니다
- **실제 비상정지**는 반드시 하드웨어 E-STOP(서보 전원 차단)으로 해야 합니다
