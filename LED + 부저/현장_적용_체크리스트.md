# LED + 부저 현장 적용 체크리스트

이 문서는 실제 로봇팔에 LED + 부저 표시 장치를 붙일 때 순서대로 확인하기 위한 현장용 요약본입니다. 자세한 설명은 `README.md`, 배선은 `docs/wiring.md`, CAN 프레임은 `docs/can_status_frame.md`를 기준으로 합니다.

## 1. 역할 분리

```text
Raspberry Pi = 로봇팔 작업 상태 판단, rack_count 관리, CAN 상태 송신
표시용 Arduino Nano = CAN 0x410 수신, LED/부저 출력만 담당
```

표시용 Nano는 TOF용 Nano가 아닙니다. 로봇팔 제어 Nano도 아닙니다. 별도 Nano를 사용합니다.

## 2. 하드웨어 준비

```text
CNC 박스:
  파란 LED 1개
  빨간 LED 1개
  초록 LED 1개

적재함 또는 작업자 알림 위치:
  압전 부저 1개

빵판:
  Arduino Nano
  MCP2515
  저항 3개
  부저 배선
```

LED는 박스에 5mm LED 홀더 또는 베젤로 고정합니다. LED 다리에는 최종적으로 납땜 또는 단자 처리 후 수축튜브로 절연합니다.

## 3. 핀맵 확인

```text
D4 = 빨간 LED
D5 = 초록 LED
D6 = 압전 부저
D7 = 파란 LED

D2  = MCP2515 INT
D10 = MCP2515 CS
D11 = MCP2515 MOSI
D12 = MCP2515 MISO
D13 = MCP2515 SCK
```

각 LED는 반드시 220~330옴 저항을 거칩니다.

```text
Arduino 핀 -> 저항 -> LED +
LED - -> GND
```

## 4. 상태 표시 기준

| 상태 | 실제 의미 | 표시 |
|---|---|---|
| `CNC_EMPTY` | 홈 대기, 탐색, 집기, CNC 이동, CNC 비어 있음 | 파란 LED ON |
| `CNC_OCCUPIED` | CNC 안으로 투입 시작, 가공 대기, 가공 중 | 빨간 LED ON |
| `CNC_DONE_WAIT` | 가공 완료, 회수 대기, CNC에서 픽업 중 | 초록 LED 느린 점멸 |
| `RACK_LOADED` | 적재함에 1개 적재 완료 | 파란 LED ON + 부저 3번 |
| `RACK_FULL` | 적재함 2개 만재 | LED OFF + 부저 반복 |
| `ERROR` | 에러/비상/작업 실패 | 전체 LED 빠른 점멸 + 부저 |

## 5. 실제 로봇팔 적용 지점

```text
홈 대기 / 물체 탐색 / 물체 집기 / CNC로 이동
-> CNC_EMPTY

로봇팔이 CNC 안으로 물체를 넣는 동작 시작
-> CNC_OCCUPIED

CNC 가공시간 20초 진행 중
-> CNC_OCCUPIED 유지

가공시간 종료
-> CNC_DONE_WAIT

로봇이 가공품을 들고 CNC 밖 안전 위치까지 후퇴 완료
-> CNC_EMPTY

적재 위치에서 그리퍼 열기 완료 + 적재함 밖으로 후퇴 완료
-> RACK_LOADED
-> rack_count += 1

rack_count >= 2
-> RACK_FULL
-> 다음 사이클 정지
```

## 6. 가공시간 설정

기본 가공시간은 20초입니다. 코드에 직접 박아두지 말고 설정값으로 관리합니다.

```json
{
  "cnc_process_sec": 20,
  "rack_capacity": 2
}
```

나중에 가공시간을 바꿔도 신호 체계가 꼬이지 않도록 `CNC_OCCUPIED`가 시작된 시각 기준으로 계산합니다.

## 7. 적재함 카운트 기준

센서 없이 1차 구현에서는 로봇 명령 완료 기준으로 판단합니다.

```text
적재 위치 도착
-> 그리퍼 열기 완료
-> 적재함 밖 안전 위치로 후퇴 완료
-> 적재 성공으로 인정
-> rack_count += 1
```

적재함은 2개 적재 기준입니다.

```text
rack_count = 0 -> 1번 위치에 적재
rack_count = 1 -> 2번 위치에 적재
rack_count = 2 -> RACK_FULL, 다음 작업 정지
```

적재함을 실제로 비운 뒤에는 RPi 대시보드나 운영 스크립트에서 `rack_count = 0`으로 초기화합니다.

## 8. 1차 테스트 순서

```bash
# 파란 LED
python3 "LED + 부저/rpi/cnc_status_buzzer.py" --interface can0 --state CNC_EMPTY --once

# 빨간 LED
python3 "LED + 부저/rpi/cnc_status_buzzer.py" --interface can0 --state CNC_OCCUPIED --remaining 15 --once

# 초록 LED 점멸
python3 "LED + 부저/rpi/cnc_status_buzzer.py" --interface can0 --state CNC_DONE_WAIT --once

# 적재 완료 부저
python3 "LED + 부저/rpi/cnc_status_buzzer.py" --interface can0 --state RACK_LOADED --rack-count 1 --once

# 만재 부저
python3 "LED + 부저/rpi/cnc_status_buzzer.py" --interface can0 --state RACK_FULL --rack-count 2 --rack-capacity 2 --once
```

CAN 없이 payload만 확인할 때는 `--dry-run`을 붙입니다.

## 9. 최종 적용 전 확인

```text
[ ] 표시용 Nano가 TOF용 Nano와 다른 보드인지 확인
[ ] D7이 버튼이 아니라 파란 LED로 연결됐는지 확인
[ ] LED 3개 각각 저항이 들어갔는지 확인
[ ] MCP2515 크리스털이 8MHz/16MHz 중 무엇인지 확인
[ ] CANable/MCP2515 종단저항이 버스 양 끝에만 있는지 확인
[ ] RPi에서 rack_count 초기화 방법을 정했는지 확인
[ ] CNC 가공시간을 설정값으로 바꿀 수 있는지 확인
[ ] RACK_FULL 상태에서 다음 CNC 투입을 막는지 확인
[ ] E-Stop이 STS3215 서보 전원을 물리적으로 차단하는지 확인
```

## 10. 발표용 한 문장

```text
로봇팔의 실제 작업 단계는 Raspberry Pi가 판단하고, 별도 Arduino Nano는 CAN으로 받은 상태에 따라 CNC 비어 있음은 파란색, CNC 점유/가공 중은 빨간색, 가공 완료/회수 대기는 초록 점멸, 적재 완료와 만재는 부저로 표시한다.
```
